# Migrating from v0.3 to v0.4 — native candle as the only ML runtime

v0.4 is the **N-03 cutover** milestone. It deletes the fastembed-rs / ONNX
Runtime / Ollama (production) / candle-gemma backends and ships
candle-native `granite-embedding-311m-multilingual-r2` (embedder) +
`bge-reranker-v2-m3` (reranker) as the single supported runtime.

This document covers:

1. What broke and why (decision log).
2. Operator migration recipe (env vars, model staging).
3. SDK API rename map (Python + TypeScript + Rust).
4. Build-feature rename map.
5. Rollback procedure.

If you only want the TL;DR: **run `huggingface-cli download` twice, drop
two env vars from your orchestrator, and rename your SDK factory calls
from `.fastembed(...)` to `.native()`.** Concrete commands below.

---

## 1. What broke

### Deleted crates / modules

| Surface | v0.3 location | v0.4 replacement |
|---|---|---|
| `FastembedEmbedder` | `lunaris-embed::fastembed` | `lunaris-embed-native::NativeEmbedder` |
| `CandleEmbeddingGemma` | `lunaris-embed::candle_gemma` | `lunaris-embed-native::NativeEmbedder` |
| `OllamaEmbedder` (production) | `lunaris-embed::ollama` | `lunaris-embed-remote::OllamaEmbedder` (feature-gated) |
| `FallbackEmbedder<P,F>` | `lunaris-embed::fallback` | — (removed; no fallbacks in v0.4) |
| `BgeRerankerV2M3` | `lunaris-rerank::bge` | `lunaris-rerank-native::NativeReranker` |
| `FastembedReranker` | `lunaris-rerank::fastembed` | `lunaris-rerank-native::NativeReranker` |
| `NoopEmbedder` | `lunaris-embed::noop` | `lunaris-core::NoopEmbedder` |
| `NoopReranker` | `lunaris-rerank::noop` | `lunaris-rerank::noop` (unchanged location) |

### Retired env vars

| v0.3 | v0.4 |
|---|---|
| `LUNARIS_EMBEDDER_BACKEND` ∈ `{fastembed,candle,ollama,noop}` | **removed** |
| `LUNARIS_RERANKER_BACKEND` ∈ `{fastembed,candle,noop}` | **removed** |
| `LUNARIS_FASTEMBED_CACHE_DIR` | **removed** |
| `LUNARIS_OLLAMA_URL` (production embedder) | renamed `LUNARIS_EMBEDDER_OLLAMA_URL` (escape hatch only) |
| `FASTEMBED_EXECUTION` (ORT EP) | **removed** |

### Retired Cargo features (umbrella `lunaris-memory`)

| v0.3 | v0.4 |
|---|---|
| `--features fastembed` | **removed** |
| `--features candle` (forwarded to embed+rerank) | now forwards ONLY to `lunaris-extract` + `lunaris-verify` |
| `--features ollama` (forwarded to embed+extract+verify) | now forwards ONLY to extract + verify |
| `--features candle-only` (air-gap escape) | **removed**; the native default IS the air-gapped path |
| `--features recommended` (= `fastembed + candle`) | **removed** |
| `--features fastembed-coreml` / `fastembed-cuda` (ORT EPs) | **removed** |
| — | `--features embed-remote` (NEW; gates `lunaris-embed-remote`) |
| — | `--features embedder-gguf` (NEW; gates `NativeQuantizedEmbedder`) |
| — | `--features reranker-gguf` (NEW; gates `NativeQuantizedReranker`) |

### Retired SDK factories

See §3 below for the full Python + TypeScript rename map.

## 2. Operator migration recipe

### 2.1 Stage the model weights

Run once per deployment host. The total payload is **~1.3 GiB** (granite-r2
FP16 + bge-reranker FP32).

```bash
# Embedder — IBM granite-embedding-311m-multilingual-r2 (Apache-2.0)
huggingface-cli download ibm-granite/granite-embedding-311m-multilingual-r2 \
  --local-dir ~/.cache/lunaris/models/granite-embedding-311m-multilingual-r2

# Reranker — BAAI bge-reranker-v2-m3 (Apache-2.0)
huggingface-cli download BAAI/bge-reranker-v2-m3 \
  --local-dir ~/.cache/lunaris/models/bge-reranker-v2-m3
```

Each directory MUST contain `model.safetensors`, `tokenizer.json`, and
`config.json`. The umbrella resolver checks these files at
`Lunaris::open()` time and falls back to `NoopEmbedder` / `NoopReranker`
with a `tracing::warn!` banner if any artifact is missing.

### 2.2 Update env-var configuration

Drop these entries from your orchestrator (Helm chart / k8s deployment /
systemd unit / docker-compose):

```diff
- LUNARIS_EMBEDDER_BACKEND=fastembed
- LUNARIS_RERANKER_BACKEND=fastembed
- LUNARIS_FASTEMBED_CACHE_DIR=/var/cache/lunaris/fastembed
- FASTEMBED_EXECUTION=coreml
```

If your operator workflow needs a non-default cache location, add:

```bash
export LUNARIS_EMBEDDER_DIR=/var/cache/lunaris/models/granite-embedding-311m-multilingual-r2
export LUNARIS_RERANKER_DIR=/var/cache/lunaris/models/bge-reranker-v2-m3
```

### 2.3 (Optional) Quantized GGUF

For RSS-constrained deployments, build with `--features embedder-gguf,reranker-gguf`
and set:

```bash
export LUNARIS_EMBEDDER_GGUF=/path/to/granite-r2.Q4_K_M.gguf
export LUNARIS_RERANKER_GGUF=/path/to/bge-reranker-v2-m3.Q5_K_M.gguf
```

The N-01 step 2 / N-02 step 2 phase docs cover the GGUF conversion recipe
(via llama.cpp `convert_hf_to_gguf.py` + `llama-quantize`). Q4_K_M for the
embedder hits a ≤0.5% mean cosine drift gate; Q5_K_M-imatrix for the
reranker hits the ≤0.10 max-drift gate.

### 2.4 (Optional) Ollama escape hatch

Operators on air-gapped networks with a pre-existing Ollama deployment
who cannot stage the candle weights can opt into the HTTP escape hatch:

```bash
# Rebuild with the feature
cargo build -p lunaris-server --features embed-remote

# Point at the local Ollama daemon
export LUNARIS_EMBEDDER_OLLAMA_URL=http://localhost:11434
```

This path emits a `tracing::warn!` banner per process; it is NOT the
supported v0.4 runtime and will not receive performance optimizations.

## 3. SDK rename map

### 3.1 Python (`pip install lunaris-memory`)

```python
# v0.3
from lunaris import EmbedderConfig, RerankerConfig

emb = EmbedderConfig.fastembed(execution="coreml")
rer = RerankerConfig.fastembed(execution="cpu")

# v0.4
from lunaris import EmbedderConfig, RerankerConfig

emb = EmbedderConfig.native()              # default cache dir
rer = RerankerConfig.native()              # default cache dir

# Or with explicit dirs:
emb = EmbedderConfig.native(model_dir="/var/cache/lunaris/models/granite-r2")
rer = RerankerConfig.native(model_dir="/var/cache/lunaris/models/bge-reranker")

# Q4 GGUF (requires wheel built with embedder-gguf / reranker-gguf):
emb = EmbedderConfig.native_quantized(gguf_path="/path/to/granite-r2.Q4_K_M.gguf")
rer = RerankerConfig.native_quantized(gguf_path="/path/to/bge-reranker.Q5_K_M.gguf")
```

The retired factories — `EmbedderConfig.fastembed()`, `.from_onnx_bytes()`,
`.from_onnx_path()`, `.ollama()`, `RerankerConfig.fastembed()` — raise
`AttributeError` at import time. There is no compatibility shim: rename in
your code or pin the v0.3 wheel.

`EmbedderConfig.noop(dim=768)` and `RerankerConfig.noop()` are unchanged.

### 3.2 TypeScript (`npm i lunaris`)

```typescript
// v0.3
import { EmbedderConfig, RerankerConfig } from "lunaris";

const emb = EmbedderConfig.fastembed({ execution: "coreml" });
const rer = RerankerConfig.fastembed({ execution: "cpu" });

// v0.4
import { EmbedderConfig, RerankerConfig } from "lunaris";

const emb = EmbedderConfig.native();
const rer = RerankerConfig.native();

// Or with explicit dirs:
const emb = EmbedderConfig.native({ modelDir: "/var/cache/lunaris/models/granite-r2" });

// Q4 GGUF:
const emb = EmbedderConfig.nativeQuantized({ ggufPath: "/path/to/granite-r2.Q4_K_M.gguf" });
```

Same shape as Python — the retired factories are gone; rename or pin v0.3.

### 3.3 Rust (`cargo add lunaris-memory`)

```rust
// v0.3
use lunaris::Lunaris;
use lunaris_embed::FastembedEmbedder;
use lunaris_rerank::BgeRerankerV2M3;
use std::sync::Arc;

let embedder = Arc::new(FastembedEmbedder::new(Default::default())?);
let handle = Lunaris::open_with_embedder("moon://localhost:6390", embedder).await?;

// v0.4
use lunaris::Lunaris;
// Default — uses cache dir + canonical layout:
let handle = Lunaris::open("moon://localhost:6390").await?;

// Or BYO embedder construction:
use lunaris_embed_native::{NativeEmbedder, NativeEmbedderOpts};
use std::path::PathBuf;
use std::sync::Arc;

let opts = NativeEmbedderOpts {
    weights_path: PathBuf::from("/var/cache/lunaris/models/granite-r2/model.safetensors"),
    tokenizer_path: PathBuf::from("/var/cache/lunaris/models/granite-r2/tokenizer.json"),
    config_path: PathBuf::from("/var/cache/lunaris/models/granite-r2/config.json"),
    device: candle_core::Device::Cpu,
};
let embedder: Arc<dyn lunaris_core::Embedder> =
    Arc::new(NativeEmbedder::open(opts)?);
let handle = Lunaris::open_with_embedder("moon://localhost:6390", embedder).await?;
```

The `lunaris-embed` and `lunaris-rerank::{bge,fastembed}` modules no
longer exist. Cargo will fail to resolve. Migrate or pin v0.3.

## 4. Rollback procedure

The v0.4 cutover is a one-way migration on the SDK API surface. To roll
back:

1. **Pin v0.3.x** in your Cargo.toml / package.json / requirements.txt.
   The fastembed + ORT transitive surface returns; expect ~150 MB of
   prebuilt ORT binaries to download on first `cargo build`.
2. **Restore the env vars** removed in §2.2.
3. **Re-stage fastembed cache** (auto-downloaded on first call to
   `EmbedderConfig.fastembed()`).
4. **Vector indices** — granite-r2 and EmbeddingGemma both produce
   768-d L2-normalized vectors. The on-disk indices are compatible across
   the rollback in either direction; you do NOT need to re-ingest.
   Recall quality WILL shift (different models) — re-run your eval gate
   after the rollback to confirm the shift is acceptable.

There is no in-place revert path inside a single deployment — the v0.4
binary cannot load the v0.3 fastembed backend and vice versa. Rollback =
pin the v0.3 dependency tree.

## 5. Performance and quality expectations

Per the N-01 / N-02 verification phases:

- **Embedder cosine drift** vs HF `sentence-transformers` reference: mean
  ≤0.005, max ≤0.02 (FP16 default); ≤0.005 mean / ≤0.05 max (Q4_K_M GGUF).
- **Reranker score drift** vs FP32 reference: ≤0.10 max
  (Q5_K_M-imatrix GGUF).
- **Recall p50 budget** unchanged at ≤25 ms (blueprint §4.2). Native
  embedder + reranker are wired through the same RETRIEVE-06 pipeline.
- **Binary size** drops ~30-50% (the ORT prebuilt downloader +
  hf-hub-native-tls were the heavy transitive deps).

If you observe a recall regression after migrating: open an issue with
the eval split + scope name; we'll triage against the N-04 release-gate
soak.
