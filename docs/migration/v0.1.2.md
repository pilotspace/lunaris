# Migration Guide: v0.1.1 to v0.1.2

## Consolidator default flip

**What changed:** `ConsolidatorPipelineHandle::default()` now returns an
`ActRConsolidator` instance instead of `NoopConsolidator`. This means any
`Lunaris::open(url)` call without an explicit `set_consolidator()` override
will run the real ACT-R consolidation pipeline (Anderson 1996 base-level +
Petrov 2006 O(1) incremental scoring + Leiden community detection).

**Who is affected:** Anyone running `Lunaris::open` without an explicit
consolidator override. The three-surface toggle (code / env / config) still
works -- only the default resolution changed.

**How to retain v0.1.1 behavior:**

```bash
# Option 1: environment variable (recommended for operators)
export LUNARIS_CONSOLIDATOR_BACKEND=noop

# Option 2: code (for library consumers)
handle.consolidator_pipeline()
    .set_consolidator(Arc::new(NoopConsolidator));
```

**Why:** The `NoopConsolidator` default was a v0.1.1 deferral because the
full `ActRConsolidator` implementation was not yet authored. Phase 16 of
v0.1.2 completed the implementation, calibrated the promotion_rate SLO,
and validated isolation (Helios-scoped consolidation does not touch
non-Helios episodes).

## EVAL-05 `promotion_rate` now enforced

**What changed:** The `eval_05_helios_10k` binary now exits non-zero if
`promotion_rate` falls outside the enforced band **[0.00, 0.01]**.
Previously (v0.1.1), promotion_rate was informational only.

**Band lineage:** Calibrated via 6 x EVAL-05 runs (3 x Moon + 3 x Postgres)
in Plan 16-04. Observed median = 0.0000, MAD = 0.0000, half_band =
max(2 x MAD, 0.01) = 0.01. Artifacts at
`milestones/v0.1.2-CONSOL-CALIBRATION/SUMMARY.md`.

**What a failing CI run looks like:**

```
promotion_rate 0.050000 outside enforced band [0.0000, 0.0100]
(calibrated in Plan 16-04; see milestones/v0.1.2-CONSOL-CALIBRATION/SUMMARY.md)
```

The binary still writes the JSON envelope on failure so operators have
evidence for investigation.

## Who needs to act?

| Surface | Action required |
|---------|----------------|
| Helios (Rust-native) | No action -- uses `Lunaris::open` which picks up the new default automatically. Helios-scoped consolidation (`helios:fs/` prefix) is unchanged. |
| `lunaris-py` (PyO3) | No action -- Python SDK delegates to the Rust handle; default flip propagates. Set `LUNARIS_CONSOLIDATOR_BACKEND=noop` if needed. |
| `lunaris-ts` (napi-rs) | No action -- TypeScript SDK delegates to the Rust handle; default flip propagates. Set `LUNARIS_CONSOLIDATOR_BACKEND=noop` if needed. |
| CI pipelines running `eval_05_helios_10k` | **Review:** the binary now enforces promotion_rate. If your pipeline relied on the informational-only behavior, verify your observed rate falls within [0.00, 0.01]. |
| Custom consolidator backends | No action -- explicit `set_consolidator()` calls override the default. |
