# lunaris-rerank-native

Native candle XLM-RoBERTa cross-encoder reranker for `BAAI/bge-reranker-v2-m3`.

Milestone **v0.4 N-02 step 1**. Companion to `lunaris-embed-native` (N-01).
Q4_K_M quantized variant is N-02 step 2 — see the parent milestone tracker.

## Model card

| Field             | Value                                              |

| HF id             | `BAAI/bge-reranker-v2-m3`                          |
| License           | Apache-2.0                                         |

## Public surface

- [`NativeReranker`] — `lunaris_rerank::Reranker` impl, cheap-clone `Arc<Inner>`.
- [`NativeRerankerOpts`] — construction options (paths + device).
- [`BGE_RERANKER_V2_M3_DIM`] / [`BGE_RERANKER_V2_M3_MAX_SEQ`] — public constants.

```rust,no_run
use candle_core::Device;
use lunaris_rerank::{RerankCandidate, Reranker};
use lunaris_rerank_native::{NativeReranker, NativeRerankerOpts};

# async fn ex() -> Result<(), Box<dyn std::error::Error>> {
let reranker = NativeReranker::open(NativeRerankerOpts {
    weights_path: "/path/to/model.safetensors".into(),
    tokenizer_path: "/path/to/tokenizer.json".into(),
    config_path: "/path/to/config.json".into(),
    device: Device::Cpu,
})?;

let docs = vec![
    RerankCandidate { id: vec![1], text: "doc one".into(), score: 0.0, metadata: Default::default() },
    RerankCandidate { id: vec![2], text: "doc two".into(), score: 0.0, metadata: Default::default() },
];
let ranked = reranker.rerank("what is X?", docs).await?;
# Ok(()) }
```

## Drift gate

Asserted in `tests/numerical_equivalence.rs` against a 100-pair reference
fixture generated by
`scripts/spike-generate-reference-rerank-scores.py` from
`sentence_transformers.CrossEncoder("BAAI/bge-reranker-v2-m3")` (CPU fp32,
sigmoid applied):

- Max absolute score delta ≤ **0.05** per pair
- Score variance > 0.01 across the 100 pairs (non-vacuity check)

Categories (25 each):
- `en_to_en` — English query ↔ English doc, mix of relevant + irrelevant
- `en_to_vi` — English query ↔ Vietnamese doc (cross-lingual)
- `en_to_code` — English query ↔ code snippet (Python / Rust / SQL / YAML)
- `vi_to_vi` — Vietnamese query ↔ Vietnamese doc (NFC normalization end-to-end)

## Running the integration test

The IT is gated behind the `reranker-it` feature so the default `cargo test`
matrix doesn't need 1.1 GB of weights.

```bash
# 1. Generate the reference fixture + download the model (one-time).
pip install sentence-transformers==3.* torch
python3 scripts/spike-generate-reference-rerank-scores.py

# 2. The script prints the three env vars at the end. Export them, then:
cargo test -p lunaris-rerank-native --features reranker-it --release \
  --test numerical_equivalence -- --nocapture
```

The IT is skipped (not failed) when any of `BGE_RERANKER_WEIGHTS_PATH`,
`BGE_RERANKER_TOKENIZER_PATH`, `BGE_RERANKER_CONFIG_PATH` is unset, or when
the fixture's `populated` flag is `false`. CI sets all three for the
`reranker-it` job.

## CLAUDE.md compliance

- `#![forbid(unsafe_code)]` — uses the safe `VarBuilder::from_buffered_safetensors`
  loader instead of the `unsafe` mmap variant.
- No lock held across `.await` — the forward pass runs inside
  `tokio::task::spawn_blocking`; the `Arc<Inner>` provides shared immutable
  access without taking a lock on the hot path.
- All files < 1000 LOC.
- NFC normalization on both `query` and `doc` before tokenization (mirrors
  `lunaris-embed-native`'s contract; see `src/tokenizer.rs` for rationale).

## Why a new crate (vs reusing `lunaris-rerank::BgeRerankerV2M3`)?

The existing `lunaris-rerank::bge::BgeRerankerV2M3` (candle path) ships raw
logits through the `Reranker` trait. v0.4 standardises on the sigmoid-bounded
score so downstream RRF / score thresholding sees a calibrated `[0, 1]` value
in the same band as cosine similarity from the embedder. The new crate also
adds the NFC-normalize pre-pass that the v0.3 path was missing.

The N-03 cutover (separate spawn) flips downstream callers to `NativeReranker`
and deletes the old candle/fastembed reranker paths.
