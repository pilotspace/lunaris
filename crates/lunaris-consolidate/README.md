# lunaris-consolidate

ACT-R activation-based memory consolidator for the [Lunaris](https://github.com/pilotspace/lunaris) agent
memory engine.

This crate is the ACT-R consolidator — closed-form Anderson 1996 base-level activation, deterministic by design, no LLM in the consolidation loop.

## Use

```toml
[dependencies]
lunaris-consolidate = "0.2"
```

See the [Lunaris repository](https://github.com/pilotspace/lunaris) for
the umbrella crate, the 10-minute quickstart, the architecture overview,
and benchmarks.
